Publier une nouvelle version

  1. Dans le dépôt privé : même numéro dans Cargo.toml, apps/desktop/Cargo.toml et tauri.conf.json, puis git tag vX.Y.Z et git push origin vX.Y.Z.
  2. Attendre la construction (Publication), relire le brouillon et le publier.
  3. C'est automatique ensuite : copie vers le dépôt public (Diffusion publique), signature (Signature), puis les applications installées proposent la mise à jour au démarrage suivant.

En cas de problème sur une version : publiez une version corrigée avec un numéro supérieur. Ne supprimez pas une version déjà diffusée ; les applications ne reviennent jamais à une version antérieure.
